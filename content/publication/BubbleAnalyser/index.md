title: "Bubble Analyser — An open-source software for bubble size measurement using image analysis"

publication: "*Minerals Engineering*"
abstract: "Bubble Analyser is open-source software for measuring bubble size distributions from photographs, a key measurement in processes such as froth flotation. Its standard image-processing algorithm was benchmarked against manually segmented images, with errors below 5% in the Sauter mean diameter, and the software is designed so that other researchers can plug in and compare new segmentation algorithms."
